# Third-Party Code Register

**Current count: 0.** No third-party dependencies, vendored code, or
copied assets exist in the repository at this milestone.

Policy (per LICENSE.md and the clean-room protocol):

1. Every external dependency must be added here **before** it is used,
   with: name, version, source URL, license, and the reason it is needed.
2. License compatibility is decided against the component map in
   LICENSE.md.
3. Microsoft code, headers, SDK assets, icons, and documentation text are
   prohibited as sources. Publicly documented *behavior* may be
   re-implemented from scratch only, verified by black-box testing.
4. Vendored code is committed in full (no download-at-build-time) so that
   every build is reproducible and auditable.
